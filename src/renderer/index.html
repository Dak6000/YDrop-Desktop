Guide d'utilisation
Tout ce qu'il faut savoir pour utiliser YDrop efficacement.
⬇ Télécharger une vidéo YouTube INTERNET REQUIS
1
Collez le lien
Copiez l'URL depuis YouTube et collez-la dans le champ. YDrop détecte automatiquement le lien et lance l'analyse dès le collage.
2
Choisissez le format
Sélectionnez la qualité vidéo (360p à 4K) ou un format audio (MP3, FLAC, WAV, M4A, OGG). Les formats audio extraient uniquement la piste sonore.
3
Définissez le dossier de sortie
Cliquez sur Parcourir pour choisir où enregistrer le fichier. Le dossier est mémorisé pour les prochains téléchargements.
4
Téléchargez
Cliquez sur Télécharger. La barre de progression affiche l'avancement en temps réel. Le fichier apparaît dans les résultats à la fin.
✂ Découper une vidéo 100% HORS LIGNE
1
Importez votre vidéo
Cliquez sur la zone d'import ou glissez-déposez un fichier MP4, MOV, AVI, MKV ou WEBM. La vidéo est traitée entièrement en local par ffmpeg — aucune donnée n'est envoyée sur internet.
2
Sélectionnez la plage
Utilisez les poignées de la timeline (glissez les barres roses) ou saisissez les temps manuellement. Cliquez sur Aperçu pour vérifier la sélection.
3
Choisissez le ratio de sortie
Original conserve les proportions. Les autres ratios recadrent et redimensionnent : 9:16 pour TikTok/Reels, 1:1 pour Instagram carré, 4:5 pour portrait, 16:9 pour YouTube.
4
Définissez la durée des segments
YDrop découpe automatiquement la plage sélectionnée en morceaux de durée égale (15s, 30s, 1min…). Utilisez Calculer segments pour voir la liste avant de lancer.
5
Nommez vos fichiers
Mode Nom de la vidéo : génère MaVideo_part01.mp4, MaVideo_part02.mp4… Mode segment_XX : nommage générique. Vous pouvez aussi saisir un nom personnalisé.
Paramètres
Configurez YDrop selon vos préférences. Les réglages sont sauvegardés automatiquement.
